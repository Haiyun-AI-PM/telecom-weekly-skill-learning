# 经营周报核验与行动建议

## 何时使用

- 手上有一份或多份周期的经营周报或漏斗数据（线索、有效触达、预约、办理等逐级数量），要判断它算得对不对、结论站不站得住。
- 要在周会上给出"有依据的判断 + 可验收的行动"，而不是复述数字。
- 不适用：需要预测、需要归因建模、需要采集外部数据、需要替代业务负责人拍板的场合。

## 输入要求（缺则先问，不要猜）

至少需要以下六项；缺任何一项先向用户确认，不要用默认值补齐：

1. 统计周期与自然周定义（起止日期、是否跨月）。
2. 客户群口径（是否为同一批客户、是否跨期去重、是否含结转订单）。
3. 逐级数量字段（线索 → 有效触达 → 预约 → 办理），逐级给出。
4. 每个字段的定义与统计口径说明（什么算"有效触达"、什么算"办理"）。
5. 数据来源与证据等级（统计报表 / 系统导出 / 口头反馈 / 个人估计）。
6. 期望产出形式（口头要点 / 书面分析 / 周会材料）。

## 分析步骤

1. **口径检查**：核对周期是否可比、客户群是否同一、字段定义是否前后一致、跨期结转是否被排除。口径不一致就停下说明原因，不强行比较。
2. **复算四率**：每一率都用原始分子与分母重算，不引用材料里已有的率。计算保留足够精度，只在展示层四舍五入。
3. **变化表达**：率的绝对差用百分点，数量的绝对差用人或单；数量与率都可以再算相对变化百分比。两种表示并列给出，不混用、不互相冒充。
4. **四栏分离**：把材料里的话拆成四栏——事实（可直接由数据读出）、反馈（来源陈述，标注来源与证据等级）、假设（待验证的因果解释）、缺证据（要回答但材料没有的）。
5. **定位拖累段**：按漏斗顺序逐段看哪一段转化变化最大。需要时做分解，见"可选高级推导"；并明确这只是数值分解。
6. **行动建议**：最多 3 项，只针对已识别的缺口或断点。每项写清角色、建议时限、验收对象、衡量指标、回看方式，并统一标注"待负责人确认"。
7. **自检**：按"核验规则"逐条过一遍，未通过的退回对应步骤重写并记录原因。

## 异常处理（必须先声明，不得静默修正）

| 情形 | 处理方式 |
|---|---|
| 字段缺失 | 不补默认值；标注缺失字段，并说明哪些结论因此不能下 |
| 负数或非整数计数 | 视为数据质量问题，标注后回来源核对，不参与比率计算 |
| 零分母 | 该率标记为"不可计算"，不写 0%，不写无穷 |
| 前期为 0 | 相对变化标记为"不可计算"，只给绝对量变化 |
| 数量倒挂（下级大于上级） | 判定为口径或去重规则不一致，暂停分析并要求核对 |
| 周期长度或客户群口径不可比 | 不做跨期比较；改为分别描述，或只在同口径内比较 |

## 核验规则

- **V1 原始计数一致**：每个计数与来源逐项核对，不改写、不四舍五入。
- **V2 率可复算**：每个率都能由原始分子与分母独立算出。
- **V3 单位正确**：百分点与相对百分比并列且标注正确，数量绝对差用人或单。
- **V4 分栏合规**：没有把反馈升格为事实，没有把假设写成结论。
- **V5 证据等级不变**：沿用来源自身的证据等级，有统计支撑的反馈不降级为"未统计"，反之也不升级。
- **V6 结论不越界**：不推断客户质量、人员能力、竞争对手等外部因素为已证事实。
- **V7 行动可验收**：建议不超过 3 项，每项四要素齐全、标注待确认、给出回看方式。

任一条不通过：退回对应步骤重写，并在核验记录里写明不通过原因与处理方式。

## 人工确认边界

- 事实栏的确认权在业务负责人，本技能不单方定稿。
- 因果解释一律停留在"待验证"，验证方式与责任人由人工指定。
- 行动建议的采纳、时限与验收口径，需负责人确认后才算生效。
- 涉及对外口径、考核结论、对客户或员工的评价，一律交人工判断。
- 数据质量存疑（缺失、负数、倒挂）时，先人工核对来源，分析里不代替更正。

## 可选高级推导（非必做）

- **逐段贡献分解**：按漏斗顺序逐项替换，得到各段对整体变化的带符号贡献。不同顺序结果不同，必须说明所用顺序；带符号贡献合计为 100%。
- **对称分摊分解**：把多因素影响更均匀地分摊，仅作可选附录。

两者都只是数值分解，不证明业务因果，不用于定责或考核归因。

## 输出结构

1. 一句话判断（不超过两行，含口径与关键变化）
2. 事实表（原始值、复算率、单位、变化表示）
3. 反馈 / 假设 / 缺证据三栏
4. 行动建议表（≤3 项，四要素 + 回看方式，标注待确认）
5. 核验记录（通过项与未通过项及处理）
6. 附录（可选：分解明细与算式）

## 非目标

- 不做预测、不做客户分群建模、不替代业务决策。
- 不采集外部数据、不联系客户、不指派任务。
- 不在技能里内置任何具体周期的数值、结论或本机路径；所有数字都来自当次输入。

## 外部依赖

无需安装第三方依赖；只需要能读取用户提供的周报数据与业务口径说明。
