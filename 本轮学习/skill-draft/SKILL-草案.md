## 0. 拟定技能名与一句话职责

**拟定名**：`grid-funnel-weekly-review`（网格经营周报漏斗核验与复盘）

**职责**：给一份同周漏斗周报数据，按业务口径复算各层率、把变化拆到量与率、把"事实／反馈／因果假设／待补证据"分开，输出可核验的分析和不超 3 项带验收口径的行动建议。**不替人下因果结论。**

**适用**：网格／营业厅同周漏斗周报（线索→有效沟通→预约→办理），需要回答"哪一段变了、变了多少、能证明什么"。
**不适用**：跨周／生命周期转化分析；缺分子分母只有百分比的材料；需要归因到具体客户或个人的场景。

---

## 1. 输入要求（缺一即停，不猜补）

| # | 必需要素 | 具体形态 | 缺失时处理 |
|---|---|---|---|
| 1 | 各层原始计数 | 线索、有效沟通、预约、办理四个**分子分母原始值**，两周（或多周）各一组 | 只有百分比 → 停止，要求补原始计数 |
| 2 | 漏斗口径定义 | 每个率的分子分母归属（如预约率＝预约/有效沟通）、是否去重、是否逐级嵌套 | 停止，不得自拟口径 |
| 3 | 同周/跨周规则 | 表内是否含跨周跟进与办理；同周转化与生命周期转化的边界 | 停止，误用会把口径差异当经营变化 |
| 4 | 数据性质 | 真实经营数据 / 教学样例 / 脱敏演示 | 标注不清则在产出显著位置写明"数据性质待确认"，不得默认真实 |
| 5 | 人工反馈原文（可选） | 一线反馈、取消原因等，需注明是否统计人数 | 一律标为"非结构化反馈，未统计"，不得升格为事实 |
| 6 | 缺失证据清单（可选） | 材料自带的 `missing_evidence` | 无则按标准清单自建并声明"本清单由分析者补充" |

**输出前强制打印**：输入文件名、数据性质、周期起止、四个计数、口径定义原文出处。任一为空则不进步骤。

## 2. 分析步骤

1. **登账**：把原始计数、周期、口径原文逐字落盘（不改写、不四舍五入）。
2. **复算四率**：触达率、预约率、办理率、整体办理率，全部由原始分子分母现算，**不引用任何既有结论**。
3. **两口径并列**：每个率同时给"百分点变化（pp）"和"相对变化（%）"，相对变化用未舍入值算。单位规则三条固定：人数绝对变化用人（或单）；率的绝对差用百分点（pp）；数量与率都可再算相对变化（%）。不得把 pp 写成 %，也不得禁止数量算相对变化。
4. **量差分解**：办理变化＝预约量效应＋转化率效应的逐项代入，验残差是否为 0；发现"某效应内含另一段抵消"必须点出。
5. **三因素分解**：整体办理率按触达率×预约率×办理率分解，**至少给两种代入顺序的区间**，声明"仅数学分解、非因果识别"；带符号占比合计须为 100%。
6. **反事实**：以旧率×新量算参照值，说明哪一段是抵补、哪一段是拖累。
7. **四栏归类**：事实 / 一线反馈 / 因果假设 / 待补证据，逐条落位，禁止跨栏搬运。
8. **写结论句**：限定在"哪一段变了多少、占降幅多少"，不写"因为…所以…"。跨指标排序（谁降幅最大）须注明所用口径，或干脆不排。
9. **行动建议 ≤3**：每项含 角色、建议时限、验收对象、衡量指标、回看方式，全部标"待负责人确认后执行"。
10. **自检**：过一遍第 4 节核验规则，未过的项不得发布。

**三条不可越过的边界（每条输出都要能对上）**：

- **嵌套成立只是数值一致性**：各层数量逐级不超上层，只说明同一周的计数关系自洽，**不证明两周是同一批客户**、也不证明客户集合的包含关系；材料无客户标识时必须明写"集合关系无法验证"。
- **数学分解不是业务因果**：量差分解闭合、残差 0、带符号占比合计 100%、反事实推演，都只是数值恒等；不得由此断言某一段是"原因"，更不得断言唯一主因。
- **对称归因属可选附录**：六种代入顺序取平均（对称归因）只用于消除顺序依赖，**不进入正文、不构成必做项、不新增要求**；不做该方法同样可完成分析。

## 3. 异常处理

| 异常 | 表现 | 处理 |
|---|---|---|
| A1 分母为 0 | 某周有效沟通或预约为 0 | 该率写"不可计算"，不做 0% 处理，不做同比比较 |
| A2 只有百分比 | 材料无原始计数 | 停止，要求补计数；如必须产出，全部结果标"无法复算" |
| A3 口径不一致 | 同一文件内术语或嵌套关系矛盾（如 `cohort_rule` 措辞与他处不同） | 以**本轮权威输入**为准并在报告首段声明差异，不静默采用任一方 |
| A4 周期间口径变化 | 两周的口径定义不同 | 拆成两段各自复算，禁止直接相减 |
| A5 pp 与 % 混用 | 数字对得上但单位标错 | 按单位硬性校验：率与率相减写 pp，量或率的变化率写 % |
| A6 反馈被当事实 | 材料出现"客户觉得贵"类描述 | 降级为"一线反馈，未统计人数"，并列入待验证 |
| A7 竞品/人员等因素 | 材料未提供却想写进原因 | 列入"待验证假设 + 核查动作"，不得写进结论 |
| A8 金额与客户信息 | 材料涉及价格或客户明细 | 无来源数字一律不写；不联系客户、不外发 |
| A9 建议超 3 项 | 想到多条 | 按"是否直接补 `missing_evidence` 缺口"排序，取前 3，其余放附录候选 |

## 4. 核验规则（自检清单，沿用本轮 V1–V8）

| 编号 | 检查 | 通过条件 |
|---|---|---|
| V1 | 原始计数与材料一致 | 四个数逐字相同 |
| V2 | 四率可独立复算 | 用脚本/手算从分子分母得出同一结果 |
| V3 | 百分点与相对变化双写 | 每个率两项齐备，单位正确 |
| V4 | 分解闭合 | 量差分解残差为 0；三因素分解合计等于总变、占比合计 100% |
| V5 | 归因不越界 | 未把数学分解写成因果；跨指标排序带口径 |
| V6 | 假设与事实分离 | 每条因果表述都有证据等级标注 |
| V7 | 单位不混用 | 人数绝对变化带"人或单"；率的绝对差一律 pp；相对变化一律 %（数量与率的相对变化都适用）。反向规则不成立：不存在"量只能写 %"或"量只能写人数"的单向规定 |
| V8 | 材料边界守住 | 无编造金额、客户信息；人员/竞品仅作核查对象；数据性质已标注 |

**任一项不通过 → 该稿标"待核验"，不得作为定稿。**

---

## 5. 人工确认边界（必须停下等人）

1. **任何因果结论**：可以给假设与核查路径，不能替负责人定"原因是 X"。
2. **行动建议的归属**：角色、时限、验收指标必须由负责人确认后才算生效；文稿一律写"建议／待确认"。
3. **对外口径**：上报或跨部门发布前，数据性质、口径版本、结论强度需人工签字。
4. **涉及金额、客户名单、个人考核**：本 Skill 不产出，遇到即转人工。
5. **Skill 自身的规则变更**：口径定义或核验清单改动需人工确认后升版，不在运行中自适应。
6. **新一期数据首次运行**：首轮结果必须人工比对一次，通过后才可放宽。

## 6. 输出骨架（供定稿时对齐）

```
1 一句话判断（≤2 句，不含因果）
2 关键指标（量 + 四率，两口径并列）
3 减量从哪里来（量差分解 / 三因素分解 / 反事实，均声明顺序与性质）
4 事实 / 一线反馈 / 因果假设 / 待补证据（四栏）
5 行动建议（≤3 项，五项要素齐备，全部待确认）
附录 算式、脚本、核验记录指针
```
